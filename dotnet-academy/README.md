# Souq Academy — .NET Backend من الصفر إلى الإنتاج

أكاديمية عربية محلية بالكامل لتعلّم **ASP.NET Core Backend**، بواجهة تحريرية هادئة
ومسار تعلّم متدرّج. لا تسجيل دخول، لا خادم، لا تحليلات، ولا اتصال بالإنترنت.

المحتوى ليس مجموعة مقالات منفصلة: كل درس يبني خطوة في مشروع **Souq.NET** للتجارة
الإلكترونية، ويشرح الفكرة من الصفر، ثم يفكّك الكود سطرًا بسطر، ثم يختبر فهمك.

---

## التشغيل

### فتح مباشر

افتح `index.html` في متصفح حديث. التطبيق يعمل عبر `file://` بالكامل: الدروس
مضمّنة في ملفات JavaScript، والخطوط من نظام التشغيل، ولا توجد طلبات شبكة.

### خادم محلي اختياري

```bash
./run.sh
# أو
PORT=3000 ./run.sh
```

يشغّل خادم Python ثابتًا على `http://localhost:8080`. استخدمه إذا كانت سياسة
المتصفح تقيّد `localStorage` على `file://`.

> لا تحتاج إلى `npm install` ولا build ولا قاعدة بيانات.

## الواجهة

- **صفحة مسار** شبيهة بصفحة دورة في Codecademy: تعريف، ماذا ستتعلم، إحصاءات،
  خريطة وحدات قابلة للفتح، ثم دعوة للمشروع.
- **صفحة درس** بقائمة دروس جانبية تشبه Scrimba: تقدم عام، حالة كل درس، ووقت القراءة.
- **أبيض ورمادي ولون واحد** (`#2f4bd8`)، بلا تدرجات أو ظلال لامعة أو أيقونات ملوّنة.
- **RTL** كامل، استجابة للجوال، قائمة جانبية منسدلة، وبحث فوري.
- **وضعان فاتح وداكن** بمبدّل واحد في الرأس؛ الوضع الفاتح افتراضي، والاختيار محفوظ.

## ماذا يقدّمه الدرس؟

كل درس يعرض الأقسام التالية بالترتيب:

1. **الشرح من الصفر** — المشكلة قبل الحل، والمصطلحات التقنية بالإنجليزية.
2. **الكود سطرًا بسطر** — عند توفر `walkthrough`: كل سطر/مقطع، وظيفته، وما يحدث في الخلفية.
3. **قبل / بعد** — النمط القديم مقابل النمط الحديث، مع سبب هندسي.
4. **تحت الغطاء والأداء** — CLR، GC، Kestrel، EF Core، الشبكة، أو قاعدة البيانات.
5. **أخطاء شائعة ونصائح مهنية** — 4 نصائح على الأقل لكل درس.
6. **اختبر فهمك** — 3 أسئلة بتصحيح وتفسير فوري.
7. **خطوة المشروع** — مهام Souq.NET المترابطة مع المشروع الكامل.

## الميزات المحلية

- حفظ التقدم، إجابات الاختبار، ومهام المشروع في `localStorage`.
- إكمال تلقائي للدرس عند الإجابة الصحيحة على أسئلته الثلاثة.
- إمكانية تحديد الدرس كمكتمل يدويًا.
- XP وعدّاد تقدم لكل وحدة.
- صفحة **المشروع** تجمع 231+ خطوة، مع مخطط معماري وجدول endpoints.
- صفحة **المصادر** تربط الوثائق الرسمية وخرائط roadmap.sh.
- تصدير/استيراد التقدم كملف JSON، وإعادة ضبط بعد تأكيد.
- بحث عربي/إنجليزي مع تطبيع بسيط للحروف.

    },
  ],
  compare: { /* before / after / verdict */ },
  internals: `<p>تحت الغطاء والأداء.</p>`,
  internalsTable: { head: [], rows: [] }, // اختياري
  tips: [{ title: "نصيحة", body: "شرح" }],
  quiz: [{ q: "سؤال", options: ["أ", "ب", "ج", "د"], answer: 0, explain: "لماذا" }],

- أبعد `code` في `walkthrough` عن أي backticks داخلية.
- شغّل `node --check` بعد التعديل.

## التحقق

تم اختبار الواجهة الجديدة في Chromium عبر Playwright من `file://`:

- 11 وحدة و46 درسًا في الصفحة الرئيسية، وفتح الوحدات.
- 7 أقسام في كل درس، و8–15 خطوة Walkthrough لكل درس (15 في `program-cs`).
- إجابة الاختبارات، الإكمال التلقائي، وشارة «مكتمل».
- حفظ الحالة بعد إعادة التحميل، وتحديد مهام المشروع.
- صفحة المشروع: 11 مرحلة، 231 خطوة، وتحديث النسبة عند تعليم مهمة.
- البحث، صفحة المصادر، والتنقل بين الصفحات.
- شاشة 390×844: لا تمرير أفقي، القائمة الجانبية تفتح وتغلق، والدرس يظهر كاملًا.
- لا أخطاء Console أو JavaScript.

لفحص الصياغة:

```bash
for f in assets/js/core.js assets/js/app.js assets/js/content/*.js; do
  node --check "$f" || exit 1
done
```
